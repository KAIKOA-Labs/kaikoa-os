# KAIKOA OS — Master Specification

Reviewed: 2026-10-08, Asia/Manila. Reconstructed specification; detailed original transcripts remain incomplete.

## Mission

Build a trustworthy personal operating system that reduces cognitive load, prevents important obligations from falling through the cracks, supports sound financial and strategic decisions, and makes a complex international life understandable.

Scope includes assets, responsibilities, finances, health administration, credentials, businesses, properties, vessels and long-term plans. Health, identity, family and financial document imports remain gated; scope is not authorization to import.

## Universal model

Core concepts: entities, relationships, events, obligations, evidence and provenance.

Recovered conceptual domains include Asset, Account, Document, Person, Company, Property, Vehicle, Credential, Contract, Investment, Project and Obligation. These are conceptual scope, not a claim that all have implemented interfaces or separate database tables.

## Product principles

- Data-first underneath; module-first in the interface.
- An attention-focused, mobile-first Command Center with progressive disclosure.
- Preserve unknowns, source quality and dated verification.
- Report in USD while preserving native transaction currencies.
- Distinguish opportunities from owned assets and binding obligations.
- Distinguish workflow, owner attention, due dates and scheduled dates.
- Captain AI interprets structured evidence; it is not the source of truth.
- Separate operational database, authoritative documents and secret vault.
- Human authority: observe → recommend → request approval → act within explicit authority.

The existing checkpoint preserves the broader navigation direction NOW → Email → Money → Time → Assets → Operations → Alpha. This is planning direction, not a claim that all modules exist.
